# H1—H3 假设与测量计划

本计划在目标域评测前固定。目标域图像和标签仅用于最终测试，不用于训练、挑选提示、阈值、超参数或 checkpoint。Step 0 交付测量代码和 16 张图的接口验收；以下比较组的正式训练及完整实验由后续步骤执行。

## 共同协议

- 类别顺序固定为 Atelectasis、Cardiomegaly、Consolidation、Edema、Pleural Effusion。
- `0/1` 有效；`-1`、空白的 `mask=0`，原始值保留。五类均无有效标签的样本跳过并计数，不参与训练、评测或特征对比样本集。
- 比较组共享源域划分与嵌套 10%/100% train 患者子集，种子 42、43、44；源域 val/test 和目标 test 固定。
- 主表每类计算 ROC-AUC、F1、AUPRC，再取宏平均；F1 固定阈值 `0.5`。缺少正例或负例时 AUC 为 NA；没有正例时 AUPRC 为 NA；宏平均忽略未定义项，报告有效类别数。JSON 用 `null` 表示 NA，CSV 留空。
- 官方视觉投影后单位向量为 `v`，当前权重真实维数 `d=512`；每类阳性相似度减阴性相似度得到 `q∈R^5`；`z=[v;q]∈R^517`。保存 `v/q/z`、提示向量及其层名、维度。
- 各域分别对齐同一批图像；MIMIC 患者与 CheXpert 患者不配对。图像身份、标签、mask 和协议不一致的比较必须报错。

## H1：源域增益未必转化为目标域增益

比较原始预训练、线性探针、LoRA-r8、LoRA-r16，在两个预算及三个种子上采用相同样本。

每种方法和预算记录源域 test 与目标域 test 的 Macro-AUC；计算相对原始预训练的源域增益、目标域增益，并记录：

```text
source_gain = source_method - source_pretrained
target_gain = target_method - target_pretrained
transfer_drop = source_method - target_method
```

保留正负号。Macro-F1、Macro-AUPRC 和逐类指标作为辅助结果。两种冻结分支不依赖标注预算，跨预算列出时注明复用了同一模型结果。

漂移辅助量为每种方法相对原始权重在**同一源域 test 图像**和**同一目标域 test 图像**上的 `1-cos(v_base,v_method)`。将漂移与两域增益一起分析，不以两机构图像的直接差值代替同图像前后漂移。

实现：`collect_metrics.py h1` 汇总两域 `metrics_summary_*.csv`，要求预算、种子、评测范围、阈值和各域评测集摘要一致。逐类指标由公共 evaluator 导出；漂移复用 H2 工具。

## H2：LoRA 比线性探针产生更明显的图像表征漂移

对原始模型、线性探针及两种 LoRA，在每个域内提取相同图像的 `v`：

```text
image_drift_i = 1 - cosine(v_base_i, v_method_i)
```

源域 test、目标域 test 分别报告漂移均值、标准差、P95、最大余弦漂移和最大元素绝对差。线性探针、冻结单/五模板的图像端应保持不变，单精度下最大元素绝对差不超过 `1e-5`。

分类辅助量为同一方法、预算、种子下的源域和目标域 Macro-AUC、Macro-F1、Macro-AUPRC（从公共 evaluator/H1 汇总读取）。缓存还保留 `q`、`z` 和文本提示向量，供后续定位变化来源；Step 0 的主漂移工具测量图像向量 `v`。

实现：`collect_metrics.py h2 --base ... --method ...`，按完整图像身份对齐，拒绝缺失、重复或不同图像集合。对冻结图像端附加 `--expect-frozen`，超出容差则验收失败。

## H3：少样本条件下，固定多提示可能改善目标域结果

比较原始预训练模型的单模板和五组语义等价阳性/阴性模板。列表固定在 `src/prompts.py`。仅在源域 val 确定协议，目标域不更换模板；文本编码器不更新，不做软提示训练。

每组计算阳性减阴性的差分 logit，**先对五组 logits 求均值，再做 sigmoid**。记录源域 test 与目标域 test 的 Macro-AUC，主要关注 10% 预算表中的目标域结果；同时报告两域 Macro-F1、Macro-AUPRC、逐类结果和五模板减单模板的成对指标差值。冻结分支本身不消耗源域训练标签，不将预算表的标记误解为训练了该分支。

漂移/不变性量为同图像单/五模板的 `v` 最大元素绝对差及余弦漂移；预期不超过冻结容差。`q` 和提示向量允许随模板集合改变，因此分别保存。检查推理前后参数和模型 buffers 未变，采用 `eval` 与 `no_grad`。

实现：`collect_metrics.py h3 --single ... --five ...` 对齐同域预测，计算单/五模板的各项指标及差值；分别对源域和目标域执行。图像端不变性用 H2 工具检查。Step 0 验收只在 16 张图上检查这些接口，不作性能改善结论。
